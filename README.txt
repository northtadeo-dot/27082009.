# Pastel Purple Birthday Website

1. Buka `index.html`.
2. Edit nama dan tanggal di bagian atas `script.js`:
   - `birthdayName`
   - `birthdayDate`
3. Ganti pesan pada `birthdayMessage`.
4. Masukkan foto ke folder `images` dengan nama:
   photo1.jpg sampai photo6.jpg
5. Masukkan musik ke `audio/birthday.mp3`.
6. Buka `index.html` di browser.

Tema: pastel purple + lavender garden + birthday cake + flowers + memories + music + confetti.
